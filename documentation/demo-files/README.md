# Demo files — feedback documents to upload

Four sample documents for the demo team (dataset 1). All names and companies are fictional.
Each one shows a different file type and a different kind of feedback.

**How to use:** People › open the reportee › **Records › Documents** › leave the type as *Detect type* › **Upload files** › choose the file.
Team Desk then shows **Place insights from document** (choose where each point goes) and then **Suggested actions**.

| File | Upload under | Type | What Team Desk finds (tested) |
|---|---|---|---|
| `Asha_Rao_Client_Feedback.docx` | Asha Rao | Word · client feedback | 2 achievements (Snowflake migration ahead of schedule, 6 hours saved every week), 1 strength, 3 improvement points (calmer handling, delayed updates, stakeholder communication), 1 learning (SnowPro Advanced). **Suggested actions:** recognise the achievement, address the working-relationship concern, review delivery risk, support the certification. |
| `Rohan_Kulkarni_Self_Assessment.pdf` | Rohan Kulkarni | PDF · self-assessment | Detected as **Self-assessment**. 2 achievements, 1 strength, 3 improvement points (estimation, missed deadlines, communication when blocked), 1 learning (SQL and estimation training), 2 goals. **Suggested actions:** recognise the achievement, help remove a blocker. |
| `Priya_Menon_Peer_Feedback.txt` | Priya Menon | Text · peer feedback | 1 strength (reliable, helps new joiners), 1 achievement (payment defect fixed), 1 improvement (more challenging tasks), 1 learning (AWS architect course), plus notes on her being quiet and finding work repetitive. **Suggested actions:** find a stretch assignment, support the certification, recognise knowledge sharing. |
| `Vikram_Singh_360_Feedback.xlsx` | Vikram Singh | Excel · 360 feedback | 1 strength (go-to person), 1 achievement (pricing engine, +8% conversion), 2 improvement points (delegate more, key-person risk), 1 goal (scheduler move by next quarter), plus readiness for a larger role. **Suggested actions:** recognise the achievement, rebalance the workload, recognise knowledge sharing. |

Tips for the demo:

- Show **Asha's** file live — it has the most visible "magic": achievement, a concern, a delivery risk and a certification in one short document.
- In the placing window, lines marked *Other* (like the "From:" line) are unticked by default. Untick or re-route anything you don't want, then **Place selected**.
- You can upload the same file again after removing it from the Documents list, if you want to repeat the demo.
- PDF, Word and Excel reading needs the file readers installed on the server (`npm install`, already done if the `node_modules` folder exists). Text files always work.
